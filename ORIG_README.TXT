TheGun.Exe version 3.0f
~~~~~~~~~~~~~~~~~~~~~~~
21st Century Missile Ware.

TheGun (Grown Up Notepad) is written in Microsoft Assembler (MASM) with a
build size of 6144 bytes. The file IO capacity has been rewritten to both
increase the maximum file size and to allow the viewing and editing of
binary files. This is very useful for viewing string data in binary files.

The new code design does not place an effective limit on file size and it
will currently load files in excess of 10 meg depending on available
memory. It is a fully enabled drag and drop application that has been
optimised for speed and ease of operation. It has the full search capacity
available from the operating system.

The printing capacity is handled through the operating system which is in
turn farmed out to Wordpad.Exe. TheGun will print with the margin settings
in Wordpad.Exe.

The internal architecture of TheGun has changed to reflect a newer
message processing technique. It has been modified to handle undocumented
changes in Windows XP, it properly detects if a file is read only and
will not attempt to save the file.

TheGun has continued to improve and adapt to undocumented changes in later
versions of Windows. Thanks are extended to the people who have helped by
reporting problems and assisting with the testing to ensure that it runs
correctly on later versions.
